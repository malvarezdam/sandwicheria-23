# Sandwichería 23 — Landing Page

Sitio de una página para Sandwichería 23, un local chileno de sandwiches artesanales que también ofrece **catering en grandes cantidades para empresas**.

> ⚠️ **Este es un boceto / borrador.** Los textos, precios, dirección, teléfono y correo son datos de ejemplo. Las imágenes son ilustraciones SVG genéricas (no fotos reales del local ni de los productos). Reemplaza todo esto por la información real antes de publicar el sitio de forma definitiva.

## Estructura

```
index.html        Página principal
css/styles.css     Estilos
js/main.js         Menú móvil y formulario de contacto
images/            Ilustraciones SVG de marcador de posición
```

## Secciones incluidas

- **Hero** con llamado a la acción
- **Carta**: sandwiches con precios referenciales
- **Empresas** (destacada): catering corporativo en grandes cantidades
- **Nosotros**: historia del local
- **Galería**: fotos ilustrativas
- **Ubicación y horarios**
- **Contacto**: formulario (sin backend conectado aún)

Abre `index.html` en un servidor local (por ejemplo, la extensión Live Server de VS Code) para verlo en el navegador.

Este sitio está pensado para desplegarse con **GitHub Pages** directamente desde la rama principal.
